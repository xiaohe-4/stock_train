# 排序选股模型：改进依据与算法说明

> 对应分支 / 管线：`feat/optimized-ranking-model`  
> 任务：基于沪深 300 成分股量价数据，预测未来 5 个交易日收益最高的 Top-5 组合（累计权重 ≤ 1）。

---

## 1. 问题定义与评分口径

比赛本质是**截面排序 + 加权组合**，而非全市场点收益回归：

- 每周从 HS300 中选出不超过 5 只股票；
- 提交权重与收益加权后得到组合收益；
- 本管线默认权重为：

```text
[0.50, 0.47, 0.01, 0.01, 0.01]
```

因此组合收益几乎由**前 2～3 名是否选对**决定。模型、损失、选模指标都应围绕该目标对齐，而不是最小化全部股票的 MSE。

标签定义（与开盘可交易假设一致）：

```text
未来 5 日收益 r_i = (第 t+5 日开盘价 - 第 t+1 日开盘价) / 第 t+1 日开盘价
```

并对极端收益做分位数截断（1%～99%），抑制梯度爆炸。

---

## 2. 改进依据

### 2.1 目标错配：从「预测收益」转向「选对重仓股」

若使用全截面回归或全量 ListMLE：

- 大量中低收益股票稀释梯度；
- 优化目标与提交权重不一致；
- 全量 ListMLE 的理论初始损失约 `log(N!)`（N 约为 300 时极大），训练困难。

改进方向：

1. **只强化真实收益最高的 Top-K 排序**（`K=3`，贴近重仓 Top2/Top3）；
2. **用可微软组合收益项**直接拉高与提交口径一致的期望组合收益；
3. **用加权组合绝对收益** `weighted_port_return` 做 early-stopping / 选模。

### 2.2 金融逻辑：周度涨幅更偏「边际资金」而非基本面

周度尺度上，基本面通常来不及定价，涨跌更依赖：

- 边际买盘强度；
- 筹码锁定与流动性（成交额/换手）；
- 情绪与横截面相对强弱的自我强化。

因此模型侧重量价与技术因子，并用**股票间注意力**显式建模横截面对比；同时按近端成交额筛「龙头池」，降低冷门股噪声对排序的干扰。

### 2.3 信噪比与过拟合

金融短周期信号弱、非平稳性强。对应工程选择：

| 措施 | 作用 |
|------|------|
| 序列长度 30（短于 60） | 更贴近周度有效信息窗口，减少远历史噪声 |
| 更小模型 + 更高 dropout / weight decay | 抑制过拟合 |
| 龙头池（成交额前 75%） | 缩小搜索空间，提高可学信号密度 |
| 双 seed 集成 | 降低单次训练方差 |
| 验证集与训练共用同一股票宇宙 | 避免截面注意力分布漂移 |

### 2.4 相对上一版（ListNet + Pairwise + soft Top-k）的取舍

上一版已引入 soft Top-k 收益对齐与多层 cross-stock attention，方向正确。本版进一步：

- 用 **TopK-ListMLE** 替代全分布 ListNet，更直接优化「前几名相对顺序」；
- 用 **低温 softmax 软组合收益** 替代较分散的 pairwise 组合，更贴合重仓权重；
- 引入 **龙头池 + 加权收益选模 + 多 seed**，把「可学样本」和「线上评分」对齐。

## 3. 算法总览

```text
原始量价 CSV
    │
    ├─ 时间划分：末约 2 个月作验证（含 sequence_length 上下文）
    ├─ 龙头筛选：训练集近 30 日平均成交额 Top 75%
    ├─ 特征工程：158 Alpha + 39 技术因子
    ├─ 标签：未来 5 日开盘收益（截断极端值）
    └─ 标准化：仅用训练集 fit
           │
           ▼
   Ranking Transformer
   (时序编码 → 时间注意力聚合 → 多层横截面注意力 → 打分头)
           │
           ▼
   CombinedRankingLoss
   = TopK-ListMLE(k=3) - λ · SoftPortfolioReturn
           │
           ▼
   按 weighted_port_return 选最优 checkpoint
           │
           ▼
   多 seed 分数均值 → Top-5 → 按配置权重输出
```

## 4. 数据与特征

### 4.1 划分与防泄露

1. 先按日期划分 train / val；
2. **仅在训练集**上用近 `leader_lookback_days=30` 的平均成交额排序，保留前 `train_leader_ratio=0.75`；
3. 验证集股票集合与训练龙头池对齐；
4. 预测阶段可复用保存的 `leader_stock_ids.pkl`，保持同一股票宇宙。

### 4.2 特征

默认 `feature_num = '158+39'`：

- **158**：Qlib / Alpha158 风格量价因子（K 线形态、动量、波动、量能等）；
- **39**：补充技术指标（均线、RSI、MACD、KDJ、布林、ATR、多周期收益与价差等）。

每个样本是一只股票连续 `sequence_length=30` 个交易日的特征矩阵；同一交易日的全部有效股票构成一个排序列表。

## 5. 模型结构

`StockTransformer` 前向流程：

1. **输入投影 + 正弦位置编码**  
   `[B, N, T, F] → [B·N, T, d_model]`

2. **时序 Transformer Encoder**  
   提取单票历史动态（`num_layers=2`, `d_model=128`）。

3. **Feature Attention**  
   对时间维做可学习加权池化，得到每股表征 `[B, N, d_model]`。

4. **多层 Cross-Stock Attention**（默认 2 层）  
   股票间 Multihead Self-Attention + 残差 LayerNorm；  
   支持 `key_padding_mask`，避免 batch 内 padding 假股票污染横截面交互。

5. **Ranking MLP + Score Head**  
   输出每只股票一个标量分数 `s_i`（越高表示越应被选中 / 重仓）。

设计意图：

- 时序模块回答「这只股票自身状态如何」；
- 横截面模块回答「相对其他股票是否更强」——这与排序任务同构。

## 6. 损失函数

### 6.1 Top-K ListMLE

对每个交易日截面：

1. 按真实收益 `r` 降序排列预测分 `s`；
2. 仅对前 `K` 名（默认 `K=3`）计算 Plackett-Luce 似然；
3. 分母始终使用**剩余全部股票**，保证「从全体中选对」的约束。

形式化地，对排序后的预测分数 `sorted_score`：

```text
ListMLE 损失 =
  - 对每个样本、每个排名 i（1 到 K）求和：
      sorted_score[i] - log(所有剩余股票 exp(score) 的和)
  - 再对 batch 取平均
```

预期初始损失约 `log(K!)`，远小于全量 `log(N!)`，更易优化。

### 6.2 可微软组合收益

```text
软权重 w = softmax(预测分数 s / 温度 T)
软组合收益 R_soft = Σ(软权重 w × 真实收益 r)
```

低温 `T=0.35` 使权重更集中于高分股票，近似「重仓头部」行为。

### 6.3 组合损失

```text
总损失 = ListMLE 损失 - λ × 平均软组合收益
其中 λ = 0.4
```

- 第一项：保证头部相对排序正确；
- 第二项：直接鼓励高组合收益（与赛方加权口径同方向）。

## 7. 训练与选模

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| optimizer | AdamW | `lr=2e-4`, `weight_decay=2e-3` |
| scheduler | Warmup + Cosine | warmup 5 epoch |
| dropout | 0.35 | 较强正则 |
| early stopping | patience=12 | 监控选模指标 |
| `selection_metric` | `weighted_port_return` | 与提交权重对齐的绝对组合收益 |
| `ensemble_seeds` | `[42, 123]` | 分别训练后推理取均值 |

验证指标同时记录：

- Top-5 等权收益及相对 oracle / random 的分数；
- **加权组合收益**（主选模指标）。

---

## 8. 推理流程

1. 加载各 seed 目录下的 `best_model.pth`、`scaler.pkl`、`stockid2idx.pkl`、`leader_stock_ids.pkl`；
2. 对最新交易日构造 30 日序列；
3. 若启用龙头池，仅在池内打分；
4. 多 seed 分数取平均；
5. 取 Top-5，按 `top_k_weights` 分配权重并导出。

## 10. 一句话总结

本管线把问题建模为：**在流动性更好的股票子集上，用时序 + 横截面 Transformer 学习可排序分数，并以 TopK-ListMLE 与软组合收益共同优化「选对并重仓高收益股」**，使训练目标与比赛提交口径一致。
