# 在时间 Transformer block 内加入 LSTM 记忆单元

状态：待审阅。本文只定义设计。未批准前不改模型、不训练、不覆盖 v4 排名。

不承诺收益。10bp 只是预先写死的研究用成本例子，不是佣金、价差、冲击或融券的完整成本。

## 用户意图

要改的是时间 Transformer block 的内部计算：沿时间维护 LSTM 的细胞状态 `(h_t, c_t)`，与该 block 的注意力子层写在同一次前向里，端到端训练，最后仍只有一个 score head。

下面这些做法都不算满足该意图：

- 两个模型各自打分，再平均、投票或加权。
- 在 `nn.TransformerEncoder` 外面先跑一个 LSTM 模块，再把整段序列送进现有编码器。
- 只加 sigmoid 门、GLU 或没有 `c_t` 的残差门，并把它叫做 LSTM。

## 推荐的 block 数据流

只改第二层时间 block。第一层保持现有 post-norm Transformer 层。池化、跨股票注意力、排序 MLP、score head 的接口不变。LSTM 的隐藏状态沿时间，不沿股票。每个样本窗口单独把 `(h_0, c_0)` 置零，不把状态带到下一只股票或下一个决策日。

第二层输入 `x`，形状 `[batch*股票数, 30, 128]`：

1. 时间多头自注意力，仍不使用因果 mask。`u = LayerNorm(x + Attn_time(x))`。注意力仍直接看见这 30 日里的原始投影，避免记忆单元变成瓶颈。
2. 真正的 LSTM cell，沿时间扫过 `u`。隐藏宽度 64。对每个 `t`：
   - `i_t, f_t, o_t = sigmoid(...)`，`g_t = tanh(...)`
   - 四个量都由 `u_t` 和 `h_{t-1}` 线性映射得到
   - `c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t`
   - `h_t = o_t ⊙ tanh(c_t)`
   - 返回完整的 `h_1..h_30`，不把序列收成最后一个状态再送去注意力
3. `m = Linear(64 → 128)(h)`，`y = LayerNorm(u + Dropout(m))`。残差保留注意力输出；遗忘门不能单独抹掉 `u`。
4. `z = LayerNorm(y + FFN(y))`。前馈层保留，dropout 仍用现有 0.35。不另搜正则或遗忘门偏置。

然后接现有的 `FeatureAttention`、两层跨股票注意力和原来的单个 `score_head`。模型只返回这一个 `[batch, 股票数]`。

PyTorch 的 `nn.LSTM` 含有上述 `c_t` 更新，可以作为这个子层的实现。没有细胞状态的 sigmoid 门不能作为替代。

新增参数按 `nn.LSTM(128, 64)` 加 `Linear(64, 128)` 约为 57,984。第二层因此约为 516,354，落在下文预算内。最终以实测参数量为准；若实现细节使它越界，只允许把该 LSTM 隐藏宽度改到仍满足预算的值，并在开训前写死，不能看验证结果再改。

### 另一个内部位置（本轮不训练）

同一 block 内、注意力之前先做 LSTM，再把 `x + Proj(h)` 送入注意力。这也是 block 内部，且必须输出完整 `h` 序列并保留残差。它让注意力只通过残差接触原始 token，信息更容易被细胞压扁。本轮三臂实验不跑这个顺序。它不是外部串联，也不要和“模型外面先接 LSTM”混写。

窗口内不加因果 mask。标签用的是窗口结束日之后的开盘，不在这 30 个特征日里；双向注意力不会读到标签。LSTM 本身从左到右更新，这是细胞的定义，不是额外的防泄漏约束。

## 日期与标签

研究三臂共用下面的切分，并且都使用修复后的窗口规则。v4 权重不进入这三臂。

- 开发验证的窗口结束日：`2026-06-01` 至 `2026-08-25`，共 61 个交易日。最后一天的标签退出开盘是 `2026-09-01`。
- 训练样本的退出开盘必须早于 `2026-06-01`。按交易日历，最后的训练窗口结束日是 `2026-05-22`，其进入开盘 `2026-05-25`，退出开盘 `2026-05-29`。
- 验证帧可以带 `sequence_length - 1` 个更早交易日，只供特征窗口使用。窗口结束日早于 `2026-06-01` 的日子不计分。
- 附录回放，不参与任何选择：窗口结束日 `2026-09-09` 至 `2026-10-26`。v4 已用它早停。同一公式可以算出一个数，写明“已观察，不能决定采用”。
- `2026-11-03` 至 `2026-11-09` 没有完整标签。退出开盘晚于 `2026-11-09` 的日子留作以后的前瞻数据。本 spec 不建监控、不设定时重训。

修复测试：构造单股票 40 个交易日，并事先去掉最后 5 行标签。`sequence_length=30` 时，修复后的构造器必须给出结束于最后一个仍有标签的日子的窗口。当前 `end_idx + 5 >= n` 在这个已缩短序列上会把它丢掉。测试要同时断言旧谓词失败、新谓词保留。三臂都走新谓词，所以样本数与 v4 不同，不能拿 v4 的去均值分数和新指标相减。

早停和选模只看下文的主指标，不看验证损失，也不看去均值的 `weighted_port_return`。主指标使用原始 5 日开盘到开盘收益，不截断、不去均值。训练损失仍用 v4 的 Top-3 ListMLE 与 softmax 组合；标签截断分位只在训练行上拟合。这两项在开训前固定，三臂相同，不在开发验证上搜索。

## 三臂与预算

三臂从头训练，同一数据、同一修复后的切分、同一损失、同一选模指标、同一优化器配置（`app/code/config.py` 的学习率、warmup、权重衰减、最多 80 轮、patience 12、seed 42 与 123）。

| 臂 | 时间块 | 其后 |
| --- | --- | --- |
| 原 Transformer | 现有两层编码器，重训 | 原池化、跨股票注意力、单 score head |
| 单 LSTM | 一层 `nn.LSTM`，输入 128，隐藏 192，输出完整序列；不含 Transformer 层 | 同上 |
| 内部记忆 | 上文的第二层 LSTM cell | 同上 |

参数量必须落在 458,370 的 ±15%，即 389,614 至 527,126。单 LSTM 的隐藏宽度 192 是为了靠近这个区间的起点，不是调出来的最优宽度；开训前实测，越界就只改隐藏宽度并记录。运行时间：同一切分上，内部记忆臂任一 seed 的每轮中位时间不得超过原 Transformer 重训臂的 2 倍，否则该臂失败。

禁止把任一臂的分数与另一臂平均后再去和单臂比较。

## 指标、验收、失败则不采用

每个决策日的权重仍是 `[0.50, 0.47, 0.01, 0.01, 0.01]`，其余股票为 0。换手 `= 0.5 * ||w_t - w_{t-1}||_1`，第一天换手按从全零仓位算。示例成本 `= 0.0010 * 换手`。当日龙头池等权收益记为 `r_ew`。主指标是开发验证日上的均值：

`原始加权收益 - r_ew - 示例成本`

两个 seed 各自用自己的分数计算主指标，再对这两个数取平均。不把两个 seed 的分数平均成一个组合后再算主指标。一个 seed 没有产出检查点，则整臂失败，不挑另一个 seed。

内部记忆臂只有同时高于原 Transformer 重训臂和单 LSTM 臂，才记为研究候选。即便如此，也不替换 v4 的 `result.csv` 或已发布排名。附录区间的高低不能改变这个判定。只在去均值验证分上获胜，视为不采用。

前瞻区间现在不存在可评分的新标签。没有它，本研究不能被写成严格的独立最终证明。
